# YS8 RTA Helper

**YS8 RTA Helper** は、『イースVIII -Lacrimosa of DANA-』の全実績取得RTA向けに開発した、チャート管理・タイム計測・Steam実績監視・音声読み上げを統合したRTA支援ツールです。

サブモニターでの使用を想定しており、ゲームを操作しながらグローバルホットキーによるチャート進行、タイム計測、攻略情報の確認が可能です。

ゲーム本体の改造やメモリ操作は行わず、独立した外部ツールとして動作します。

---

## 概要

- **チャート管理**
  - 現在の行動内容、注意事項、今後の手順を表示。
  - ツール内からチャートを編集可能。
- **RTAタイム計測**
  - 全体・主要区間・個別手順のタイムを計測。
  - 走行記録の保存と自己ベストとの比較。
- **攻略マップ表示**
  - 迎撃戦の敵出現位置やアイテム回収位置を表示。
  - WAVEごとのマップ切り替えに対応。
  - 登録済み攻略マップの別手順へのコピー。
  - WAVE単位でのマップ複製。
- **Steam実績監視**
  - Steamのローカル実績データから取得状況を監視。
  - 実績取得時のRTAタイムを記録。
- **音声による攻略支援**
  - VoiSona Talkによる行動指示・重要警告の読み上げ。
  - イベントごとのSE再生。
  - TTSとSEの順次再生による音声の重複防止。

---

## 機能詳細

### 1. チャート管理

RTA中に必要となる攻略情報を一つのウィンドウにまとめて表示します。

- 現在の周回・難易度の表示。
- 現在の手順と全体の進捗表示。
- 現在実行すべき行動内容の表示。
- 注意事項・攻略解説の表示。
- 今後の手順の先行表示。
- 手順ごとのチェックリスト。
- 前の手順への移動。
- 次の手順への移動。
- 主要区間の設定。
- 手順ごとの攻略マップの設定。
- 手順ごとの音声読み上げ設定。

チェックリストは、素材収集やクエスト消化など、実行順序が固定されていない複数の作業を管理する際にも使用できます。

### 2. チャート編集

専用の編集画面からチャートを直接編集できます。

- 手順の追加・削除・複製。
- 手順の並べ替え。
- 周回・分類の設定。
- 行動内容の編集。
- 注意事項・攻略解説の編集。
- チェックリストの編集。
- 主要区間の終了地点の設定。
- 攻略マップ・WAVEの編集。
- 別の手順からの全WAVEコピー。
- 読み上げ専用テキストの設定。
- 重要警告の読み上げ内容の設定。
- 手順単位での読み上げ無効化。

チャートは `chart.json` に保存されます。

既存のチャートを維持したまま、攻略ルートの変更や新しい攻略情報の追加が可能です。

### 3. RTAタイム計測

以下の3種類のタイムを同時に計測します。

| 計測項目 | 内容 |
| --- | --- |
| 総時間 | RTA開始から現在までの累計時間 |
| 主要区間 | 直前の主要区間終了地点からの経過時間 |
| 個別手順 | 現在の手順を開始してからの経過時間 |

- 計測開始。
- 一時停止・再開。
- 全手順の通過タイムの記録。
- 主要区間の通過タイムの記録。
- 手順単位の所要時間の記録。
- 手順を戻した際の直前の記録の取り消し。
- 最終手順終了時の計測終了。
- 走行終了・リセット。

タイム計測には `time.perf_counter()` を使用しています。

### 4. 走行記録・自己ベスト比較

走行中の記録をJSON形式で保存します。

- 走行開始日時。
- RTAの総時間。
- 完走・途中終了の区別。
- 各手順の所要時間。
- 各手順の累計タイム。
- 主要区間の所要時間。
- チェックリストの進捗。
- Steam実績の取得記録。

完走記録の中から最速の記録を自己ベストとして扱い、走行記録一覧から各手順の累計タイムとの差を確認できます。

途中終了した走行についても記録が保存されるため、練習やルート改善の分析に利用できます。

記録は `records/` フォルダに保存されます。

### 5. 攻略マップ表示

PNG画像を使用した攻略マップ表示に対応しています。

主に以下の用途を想定しています。

- 迎撃戦の敵出現位置。
- 制圧戦の攻略位置。
- 宝箱の回収位置。
- 採取ポイント。
- 必須アイテムの回収位置。
- 特殊な攻略ルートの確認。

マップが登録されている手順では、自動的にマップ表示欄が表示されます。

マップが不要な手順では表示欄を非表示にし、通常の攻略情報を広く表示します。

### 6. マップ・WAVE編集

専用のマップ編集画面から、PNG画像上に攻略位置を登録できます。

- PNG画像の登録。
- WAVEの追加・削除・複製。
- WAVE名称の変更。
- マップ上のクリックによる位置登録。
- 番号付きの赤丸による位置表示。
- 赤丸のサイズ変更。
- 登録位置の修正。
- 登録位置の削除。
- 出現順序の並べ替え。
- 各位置への説明文の設定。

迎撃戦では、現在のWAVEに登録されたすべての敵出現位置を同時に表示します。

敵が出現するたびに操作する必要はなく、WAVE間のみ表示を切り替えることで、戦闘中の操作負担を軽減します。

登録位置は画像に対する相対座標で管理しているため、ウィンドウサイズを変更しても位置関係が維持されます。

元のPNG画像に直接書き込みを行うことはありません。

### 7. 攻略マップのコピー・再利用

登録済みの攻略マップを別の手順へコピーする機能と、WAVE単位で複製する機能を搭載しています。

迎撃戦省略バグなどを利用する際に、同じ迎撃戦を複数回実行するルートでのチャート作成負担を軽減します。

#### 全WAVEコピー

チャート編集画面の「別の手順から全WAVEコピー」から、登録済みの攻略マップを現在の手順にコピーできます。

- WAVEが登録されている手順のみをコピー元候補として表示。
- 手順名・周回・WAVE名による検索。
- コピー元の手順番号・WAVE数の表示。
- 全WAVEの一括コピー。
- コピー先に既存のWAVEがある場合の上書き確認。
- コピー後の個別編集。

#### コピー対象

| 項目 | コピー対象 |
| --- | --- |
| PNGマップの参照先 | 対象 |
| 全WAVE構成 | 対象 |
| WAVE名称 | 対象 |
| 赤丸の座標 | 対象 |
| 赤丸のサイズ | 対象 |
| 赤丸の番号・順序 | 対象 |
| 敵・対処方法の説明文 | 対象 |
| 手順ID | 対象外 |
| 周回・分類 | 対象外 |
| 行動内容 | 対象外 |
| 注意事項・攻略解説 | 対象外 |
| チェックリスト | 対象外 |
| 主要区間設定 | 対象外 |
| TTS設定 | 対象外 |

攻略マップに関する情報のみをコピーするため、コピー先の行動内容やタイム計測設定などは維持されます。

#### 全WAVEコピーの操作方法

1. チャート編集画面を開きます。
2. コピー先の手順を選択します。
3. 「別の手順から全WAVEコピー」を押します。
4. コピー元の手順を選択します。
5. 必要に応じてコピー先のWAVEや赤丸を編集します。
6. チャートを保存します。

#### WAVE単体の複製

マップ・WAVE編集画面の「WAVE複製」から、選択中のWAVEを複製できます。

- 選択中のWAVEの直後に複製。
- PNGマップの参照先を引き継ぎ。
- 赤丸の座標・サイズ・順序を引き継ぎ。
- 各赤丸の説明文を引き継ぎ。
- 複製後のWAVE名称変更。
- 複製後の赤丸の個別編集。

敵の出現位置が一部のみ異なるWAVEなどを作成する場合に、既存のWAVEを複製して変更箇所のみを修正できます。

#### データ管理

コピー時には既存のPNGファイルを再利用するため、同じ画像ファイルが重複して保存されることはありません。

一方、WAVE構成や赤丸の情報は独立したデータとしてコピーされます。

コピー先の赤丸や説明文を編集しても、コピー元の攻略マップには影響しません。

既存の `chart.json` と互換性があり、登録済みの攻略マップをそのままコピー元として使用できます。

### 8. Steam実績監視

Steamクライアントが保存するローカル実績データを読み取り、実績の取得状況を監視します。

イースVIIIの全54実績に対応しています。

- Steamのインストール先の自動検出。
- 実績データファイルの自動検出候補の表示。
- 実績データファイルの手動指定。
- 実績取得数の表示。
- 今回の走行中に検知した実績数の表示。
- 最新取得実績の表示。
- 全実績の一覧表示。
- 未取得実績のみの絞り込み。
- 実績名・取得条件の日本語表示。
- Steam側の実績取得日時の表示。
- 実績取得を検知した際のRTAタイムの記録。
- 実績取得を検知した際のチャート位置の記録。

実績データは約0.5秒間隔で確認します。

#### 使用するSteamデータ

- AppID：`579180`
- `UserGameStatsSchema_579180.bin`
- `UserGameStats_<ユーザーID>_579180.bin`

Steam Web APIキーは不要です。

実績データの読み取りのみを行い、Steam実績の変更・解除・リセットは行いません。

なお、Steam側のローカルデータ更新タイミングに依存するため、実際の実績取得時刻とツールによる検知時刻には差が生じる場合があります。

### 9. TTS（音声読み上げ）

VoiSona TalkのローカルAPIを利用した音声読み上げに対応しています。

標準のボイス設定には「雨衣」を採用しています。

#### 標準ボイス設定

| 項目 | 設定値 |
| --- | --- |
| TTSエンジン | VoiSona Talk |
| ボイス | 雨衣 |
| VoiceName | `ui_ja_JP` |
| VoiceVersion | `2.0.0` |
| Language | `ja_JP` |
| API接続先 | `http://127.0.0.1:32766` |

#### 読み上げ対象

- 現在の行動内容。
- 手順ごとの読み上げ専用テキスト。
- 重要警告。
- WAVE切り替え通知。
- Steam実績取得通知。
- 主要区間の通過タイム。
- 現在の手順の再読み上げ。

実績取得通知やWAVE切り替え通知などは、音声設定画面から個別に設定できます。

#### 手順ごとの読み上げ設定

各手順に通常のチャート本文とは別の読み上げ専用テキストを設定できます。

例えば、画面上では詳細な攻略手順を表示し、音声では必要最低限の行動指示のみを読み上げるといった使い分けが可能です。

読み上げ専用テキストが未設定の場合は、通常の行動内容を読み上げる設定にも対応しています。

また、取り返しのつかない要素やクエスト期限などについては、重要警告として通常の行動指示とは別に設定できます。

### 10. 音声キャッシュ・事前生成

VoiSona Talkで生成した音声は、ローカルにWAVファイルとしてキャッシュします。

- 生成済み音声の再利用。
- 全手順の読み上げ音声の一括事前生成。
- 読み上げ内容の変更に対応した再生成。
- ボイス設定・話速の変更に対応した再生成。
- 非同期による音声合成。

走行前に音声を事前生成することで、RTA中の音声合成による待ち時間や処理負荷を軽減できます。

生成済みの音声は `audio_cache/` フォルダに保存されます。

### 11. SE（効果音）

各種イベントの発生時にSEを再生します。

標準SEはツール側で自動生成されるため、別途音声素材を用意する必要はありません。

| イベント | 標準SE |
| --- | --- |
| 計測開始 | 2音の上昇音 |
| 次の手順への移行 | 高音1回 |
| 前の手順への移行 | 低音1回 |
| WAVE切り替え | 2音 |
| 主要区間通過 | 3音の上昇音 |
| Steam実績取得 | 達成音 |
| 重要警告 | 低音3回 |
| RTA完走 | 4音の上昇音 |
| 一時停止・再開 | 単音 |

イベントごとに任意のWAVファイルを登録し、標準SEから変更することも可能です。

SEによってホットキー入力が正常に受理されたことを確認できるため、サブモニターを確認する頻度を減らせます。

### 12. 音声再生制御

TTSとSEを共通の再生キューで管理し、音声の同時再生を防止します。

- SEの再生終了後にTTSを再生。
- 重要警告を通常の行動指示より優先。
- 新しい手順へ進んだ際に古い読み上げを中断。
- 連続して手順を進めた場合は最新の指示を優先。
- 実績取得通知は再生中の音声が終了してから再生。
- 複数の実績取得通知を順番に再生。
- WAVE変更時に古い読み上げを中断。
- 再読み上げ時に古い音声を中断。
- リセット時に再生中・待機中の音声を停止。

固定時間による待機ではなく、実際の音声再生終了を基準に次の音声へ進みます。

#### 再生順序の例

通常の手順移行：

```text
手順移行SE
    ↓
行動内容の読み上げ
```

重要警告が設定されている手順：

```text
重要警告SE
    ↓
重要警告の読み上げ
    ↓
行動内容の読み上げ
```

音声合成・再生中もタイム計測やホットキー操作を継続できます。

### 13. 音声設定

専用の音声設定画面から各種設定を変更できます。

- TTSの有効・無効。
- SEの有効・無効。
- VoiSona TalkのAPI接続先。
- API認証情報。
- ボイスライブラリ名。
- ボイスライブラリバージョン。
- 読み上げ速度。
- TTS音量。
- SE音量。
- 読み上げ対象の設定。
- イベント別SEファイルの設定。
- テスト音声の再生。
- 全手順の音声事前生成。
- 音声処理の停止。

音声設定は `audio_config.json` に保存されます。

## 操作方法

ゲームウィンドウにフォーカスがある状態でも、グローバルホットキーによって操作できます。

### 標準ホットキー

| キー | 動作 |
| --- | --- |
| F6 | RTA計測開始 |
| F7 | 前の手順へ移動 |
| F8 | 次の手順へ移動 |
| F9 | 次のWAVEへ移動 |
| Shift + F9 | 前のWAVEへ移動 |
| F10 | 一時停止・再開 |
| F11 | 現在の手順を再読み上げ |
| Ctrl + F12 | 走行終了・リセット |

すべてのホットキーはキー設定画面から変更できます。

Windows環境では `GetAsyncKeyState` を使用したグローバルキー入力監視を行っています。

キーを押し続けた際の連続入力や、意図しない二重入力を抑制する処理も実装しています。

## ウィンドウ・表示機能

サブモニターでの使用を想定した独立ウィンドウとして動作します。

- モニターの利用可能領域に応じた起動サイズ調整。
- マウスカーソルが存在するモニターへの起動。
- ウィンドウサイズの変更。
- ウィンドウ全体のスクロール。
- 長文の自動折り返し。
- 主要区間記録の専用スクロール表示。
- 攻略情報とマップ表示の領域調整。
- マップ未使用時の表示領域の自動切り替え。
- ダークテーマ。

## 動作環境

- Windows
- Python 3
- PySide6
- keyboard
- Steamクライアント
- VoiSona Talk（TTS使用時のみ）
- 対応するVoiSona Talkボイスライブラリ（TTS使用時のみ）

### 必要ライブラリ

```bash
pip install PySide6 keyboard
```

または、`requirements.txt` を使用してインストールします。

```bash
pip install -r requirements.txt
```

TTSのAPI通信にはPython標準ライブラリを使用しています。

---

## 導入方法

1. ツール一式を任意のフォルダに配置します。
2. 必要なPythonライブラリをインストールします。
3. `start.bat` または `python main.py` で起動します。
4. Steam実績設定から実績データファイルを指定します。
5. 必要に応じてチャート・マップ・ホットキーを編集します。
6. TTSを使用する場合はVoiSona Talkを起動し、APIを有効化します。
7. 音声設定画面からAPI認証情報などを設定します。
8. テスト音声を再生し、正常に動作することを確認します。
9. 必要に応じて全手順の音声を事前生成します。

### 起動コマンド

```bash
python main.py
```

## 注意事項

- 本ツールはゲーム本体のファイルやメモリを書き換えません。
- ゲームへの自動入力やゲーム操作の自動化は行いません。
- Steam実績データは読み取りのみを行います。
- Steam実績のリセット機能は搭載していません。
- Steam実績の検知時刻は実際の取得時刻と一致するとは限りません。
- 最終実績取得によるタイマーの自動停止は行いません。
- TTSの新規音声生成にはVoiSona Talkの起動が必要です。
- API認証情報は `audio_config.json` に平文で保存されるため、外部への共有時には注意してください。
- VoiSona Talkおよび各ボイスライブラリの利用については、それぞれの利用規約に従ってください。
- コピーされた攻略マップは既存のPNGファイルを参照するため、参照先の画像ファイルを手動で削除しないようにしてください。
- RTAへの使用可否については、各カテゴリーのレギュレーションに従ってください。

## 開発目的

長時間にわたる全実績取得RTAにおいて、チャートの確認や記録管理に必要となる操作を減らし、ゲームプレイに集中できる環境を構築することを目的としています。

特に以下の点を重視しています。

- 長時間走行における操作負担の軽減。
- チャート確認による視線移動の削減。
- 取り返しのつかない要素の見落とし防止。
- 迎撃戦などにおける攻略情報の視覚化。
- 攻略マップの再利用によるチャート作成負担の軽減。
- Steam実績の取得漏れの確認。
- 詳細な走行記録による攻略ルートの改善。
- 音声通知による画面確認頻度の削減。

チャート管理・タイム計測・攻略マップ・Steam実績監視・音声支援を一つのツールに統合することで、全実績取得RTAを総合的に支援します。
